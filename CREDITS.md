# Credits

## Sound effects

The game loads these files from `public/sounds/`:

| File                         | Plays when                          |
| ---------------------------- | ----------------------------------- |
| `public/sounds/bonk.wav`     | a Bonk lands                        |
| `public/sounds/boing.wav`    | a tap lands on a Stunned Monster    |
| `public/sounds/wall-hit.wav` | a Flicked Monster hits the wall     |
| `public/sounds/caught.wav`   | the Monster is caught in its bubble |

All four are original, synthesised by `scripts/make-sounds.py` for this
project. There's no third-party audio and nothing to license.

If a third-party sound is ever added, credit it here with its source, license
and original file name, even if the license doesn't require it.
