# Credits

## Sound effects

Sound effects by **Kenney** (https://kenney.nl), released under
[CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/). No credit is
required, but it's given here anyway. Thank you, Kenney!

The game loads these files from `public/sounds/`. Each one is a Kenney file,
renamed for the role it plays:

| File                        | Plays when                         | Kenney pack    | Original file |
| --------------------------- | ---------------------------------- | -------------- | ------------- |
| `public/sounds/bonk.ogg`    | a Bonk lands                       | Impact Sounds  | _to fill in_  |
| `public/sounds/boing.ogg`   | a tap lands on a Stunned Monster   | Interface Sounds | _to fill in_ |
| `public/sounds/wall-hit.ogg`| a Flicked Monster hits the wall    | Impact Sounds  | _to fill in_  |
| `public/sounds/caught.ogg`  | the Monster is caught in its bubble | Interface Sounds | _to fill in_ |

Each Monster plays these pitched up or down a little (its voice), so pick
sounds that still work about 20% lower or higher. A missing file just stays
silent.
