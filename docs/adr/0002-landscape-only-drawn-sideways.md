# Landscape only, drawn sideways when the tablet is upright

Doodle Monsters only ever appears in landscape. When the window is taller than it is wide, the whole app draws itself turned 90° to fill the long side, so the kids turn the tablet to match. The layout never switches to a portrait version. There's no portrait version because every rule is tuned to a 1280×800 Arena and drawing surface (Monster size, speeds, Flicks, Habitat art), and a tall Arena would mean re-tuning the whole game. We don't use the Fullscreen API, the Screen Orientation API or a manifest `orientation`. Kids profiles can't install anything, so the game always opens as an allowed website inside the Amazon Kids wrapper, where a manifest has no effect. An orientation lock would need fullscreen, which would hide the Kids top bar the kids use to leave. Silk's support for either in a Kids profile is also undocumented. Fire OS's Auto-rotate toggle is in the Kids pull-down too, so kids can change it, and the game must work with it on or off. Don't "fix" this with a portrait layout or an orientation lock unless the game is reached some other way than the Kids wrapper.
