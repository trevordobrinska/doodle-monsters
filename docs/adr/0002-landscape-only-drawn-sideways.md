# Landscape only, drawn sideways when the tablet is upright

Doodle Monsters only ever appears in landscape. When the window is taller than it is wide, the whole app draws itself turned 90° to fill the long side, so the kids turn the tablet to match. The layout never switches to a portrait version. There's no portrait version because every rule is tuned to a 1280×800 Arena and drawing surface (Monster size, speeds, Flicks, Habitat art), and a tall Arena would mean re-tuning the whole game.

The game asks for fullscreen on a tap: while the page isn't fullscreen, any tap asks the browser (`requestFullscreen` with `navigationUI: "hide"`), and the tap still does its normal job. Fullscreen hides the Kids top bar, so the 16:10 Arena fills the Fire HD 8's 16:10 screen with no bars. The fullscreen probe (landscape ticket 04) showed this works in the Kids web browser: a tap made the page fullscreen at 961×601, and the system Back button leaves fullscreen, so the kids are never stuck. The Arcade's house button (suite rule 5) is the way home inside the game, so losing the top bar no longer takes away the way out. Fullscreen ends whenever the page is left or Back is pressed, and a browser only allows it during a tap, which is why every tap asks again until it's granted. If a browser refuses, the game simply stays as it was.

We don't use the Screen Orientation API or a manifest `orientation` or `display`. The probe measured that an orientation lock isn't available on the Fire HD 8, even in fullscreen ("Screen orientation lock is not available on this device"), so the sideways turn stays. Kids profiles can't install anything, so the game always opens as an allowed website inside the Amazon Kids wrapper, where a manifest has no effect. Fire OS's Auto-rotate toggle is in the Kids pull-down too, so kids can change it, and the game must work with it on or off. Don't "fix" this with a portrait layout or an orientation lock.
