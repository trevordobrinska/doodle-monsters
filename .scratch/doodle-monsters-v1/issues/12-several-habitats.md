# 12: Several Habitats

**What to build:** When a kid's Zoo grows past about 10 Monsters, it's split across several Habitats the kid can move between, so the screen never gets too crowded and the game stays smooth.

**Blocked by:** 09 (Zoo).

**Status:** ready-for-agent

- [ ] The core splits the Zoo into Habitats of about 10 Monsters max
- [ ] The kid can move between Habitats with big, obvious controls (swipe or arrows)
- [ ] A newly caught Monster goes into a Habitat with room, and the kid sees it arrive
- [ ] Saying Goodbye or catching doesn't shuffle Monsters around unexpectedly
- [ ] Core tests: "a Zoo with more than about 10 Monsters is split into several Habitats", "every Monster is in exactly one Habitat"
